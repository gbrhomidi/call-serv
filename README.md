## 🎯 نظرة عامة

**نظام تفعيل خدمات الاتصالات** هو تطبيق Android متكامل مصمم لإدارة خدمات شحن الرصيد، باقات الإنترنت، والرسائل النصية بشكل احترافي وآلي. يعتمد التطبيق على **الرسائل النصية (SMS)** كقناة تواصل رئيسية مع العملاء، حيث يقوم بتحليل الرسائل الواردة تلقائياً وتفعيل الخدمات المطلوبة بناءً على صلاحيات العميل ورصيده.

يعمل التطبيق بشكل كامل **Offline** دون الحاجة لاتصال إنترنت، مع واجهة مستخدم تفاعلية عبر **WebView** وجسر (Bridge) للتواصل مع طبقة Kotlin عبر `AndroidInterface`.

> 🏢 **النشاط التجاري:** قابل للتخصيص عبر شاشة الإعدادات  
> 📦 **Package:** `com.aistudio.dieselstationsms.kxmpzq`  
> 🎯 **Min SDK:** 21 (Android 5.0 Lollipop) | **Target SDK:** 34 (Android 14)  
> 🗄️ **Database:** SQLite  
> 🌐 **UI:** HTML/CSS/JS داخل WebView

## ✨ المميزات الرئيسية

### 📦 إدارة الخدمات
- إضافة وتعديل وحذف الخدمات (شحن رصيد، باقات إنترنت، باقات رسائل، شحن دولي)
- تحديد سعر الخدمة وكود التفعيل الخاص بها
- تفعيل/تعطيل الخدمة بسهولة
- البحث والتصفية في قائمة الخدمات

### 👥 إدارة العملاء
- إضافة وتعديل وحذف العملاء
- تسجيل 3 أرقام هاتف لكل عميل
- تحديد رصيد المودع والحد الائتماني المسموح به
- التحكم في صلاحية البيع بالأجل (نعم/لا)
- عرض الرصيد الحالي لكل عميل

### 🏭 إدارة الموردين والحوالات
- إضافة وتعديل وحذف الموردين
- تسجيل أرصدة الموردين (رصيدنا لديهم / رصيدهم لدينا)
- متابعة حالة المورد (مفعل / غير مفعل)
- دعم تحليل رسائل الحوالات الواردة

### 📨 نظام الرسائل النصية (SMS) الذكي
- **استقبال الرسائل تلقائياً** عبر `BroadcastReceiver`
- **تحليل الرسالة** باستخدام خوارزميات الذكاء الاصطناعي (مضمنة)
- **اكتشاف نية الرسالة** (طلب شحن، استعلام رصيد، طلب باقة، إلخ)
- **التحقق من العميل:** هل هو مسجل؟ هل يسمح له بالأجل؟ هل تجاوز الحد الائتماني؟
- **تفعيل الخدمة تلقائياً** عند استيفاء الشروط
- **إرسال ردود تلقائية** للعميل (تأكيد التفعيل، رفض الطلب مع السبب)
- **معالجة رسائل الموردين** (استقبال إشعارات الحوالات وتحديث الأرصدة)
- **سجل كامل** لجميع الرسائل الواردة والصادرة مع حالة المعالجة

### 🔐 الأمان والحماية المتقدمة
- **منع التكرار:** توليد Hash فريد لكل رسالة لمنع المعالجة المكررة
- **التحقق من SMSC:** قائمة بيضاء للمراكز الموثوقة لمنع التزوير
- **كشف الرسائل المشبوهة:** أنماط للكشف عن محاولات الاختراق
- **Rate Limiting:** تحديد عدد الرسائل المسموح بها لكل عميل يومياً
- **حظر مؤقت:** حظر الأرقام التي تتجاوز الحدود
- **تسجيل الأحداث الأمنية:** سجل كامل للهجمات والمحاولات المشبوهة
- **تخزين مشفر:** استخدام `EncryptedSharedPreferences` للبيانات الحساسة

### 📊 التقارير والتحليلات
- لوحة تحكم رئيسية مع إحصائيات حية (العملاء، الخدمات، الرسائل، الديون)
- تقارير العملاء: قائمة، تحليل الأرصدة، تقرير الائتمان
- تقارير الخدمات: ملخص، حسب الحالة، تحليل الأسعار
- تقارير الموردين: قائمة، تحليل الأرصدة، تقرير الحوالات
- تقارير الرسائل: ملخص، حسب الحالة، تحليل المحتوى
- تصدير جميع التقارير بصيغة JSON أو طباعتها

### ⚙️ الإعدادات والتخصيص
- **تخصيص النشاط التجاري:** اسم النشاط، الشعار، هاتف الدعم
- **الوضع الليلي/النهاري:** تبديل سلس مع حفظ التفضيل
- **المصادقة البيومترية:** دعم بصمة الإصبع والوجه (اختياري)
- **النسخ الاحتياطي التلقائي:** حفظ دوري للبيانات
- **تصدير واستيراد:** نسخ احتياطي كامل بصيغة JSON

## 📡 نظام الرسائل النصية (SMS)

### 📤 إرسال الرسائل

- **إرسال يدوي:** عبر واجهة المستخدم (زر "إرسال SMS")
- **إرسال تلقائي:** عند تفعيل خدمة للعميل، يُرسل SMS تأكيد
- **تنبيهات الديون:** إرسال تذكيرات للعملاء المتأخرين

### 📥 استقبال الرسائل (المعالجة التلقائية)

| نوع الرسالة | مثال | الإجراء |
|-------------|------|---------|
| طلب شحن رصيد | `اريد شحن 100` | التحقق من العميل، خصم الرصيد، إرسال كود التفعيل |
| طلب باقة إنترنت | `باقة انترنت 10 جيجا` | التحقق من توفر الباقة، تفعيلها للعميل |
| طلب باقة رسائل | `اريد رسائل 500` | تفعيل الباقة وإرسال تأكيد |
| استعلام رصيد | `كم رصيدي؟` | إرسال الرصيد الحالي للعميل |
| رسالة من مورد | `الشرعي لكم 4,000 ر ي` | تحليل الرسالة، تحديث رصيد المورد |

### 🛡️ طبقة الأمان (SmsSecurity)

- **توليد Hash:** منع معالجة الرسائل المكررة
- **التحقق من SMSC:** قائمة بيضاء للمراكز الموثوقة
- **كشف الرسائل المشبوهة:** أنماط للكشف عن الهجمات
- **Rate Limiting:** تحديد عدد الرسائل اليومي لكل عميل
- **حظر مؤقت:** حظر الأرقام المخالفة

## 🔌 واجهة JavaScript (AndroidInterface)

يتم التواصل بين واجهة المستخدم (HTML/JS) وطبقة Kotlin عبر `AndroidInterface` المدمج في `MainActivity`:

```javascript
// مثال: جلب قائمة العملاء
const result = await apiCall('get_customers');
// مثال: جلب قائمة الخدمات
const services = await apiCall('get_services');
// مثال: حفظ خدمة جديدة
const result = await apiCall('save_service', { name: 'شحن رصيد', price: 100 });
```

### دوال JavaScript المتاحة

| الدالة | الوصف |
|--------|-------|
| `apiCall(action, params)` | استدعاء دالة في طبقة Kotlin |
| `login(username, password)` | تسجيل الدخول |
| `get_customers()` | جلب قائمة العملاء |
| `save_customer(data)` | حفظ عميل (إضافة/تعديل) |
| `delete_customer(id)` | حذف عميل |
| `get_services()` | جلب قائمة الخدمات |
| `save_service(data)` | حفظ خدمة |
| `delete_service(id)` | حذف خدمة |
| `get_suppliers()` | جلب قائمة الموردين |
| `save_supplier(data)` | حفظ مورد |
| `delete_supplier(id)` | حذف مورد |
| `get_sms()` | جلب سجل الرسائل |
| `delete_sms(id)` | حذف رسالة |
| `generate_report(type)` | توليد تقرير |
| `export_data()` | تصدير جميع البيانات |
| `get_dashboard()` | جلب إحصائيات لوحة التحكم |

## 🔒 الأمان والنسخ الاحتياطي

### 🛡️ الأمان

- **تخزين مشفر:** استخدام `EncryptedSharedPreferences` للبيانات الحساسة
- **كلمات مرور مشفرة:** تخزين كلمات المرور باستخدام SHA-256 مع Salt
- **سجل التدقيق:** تسجيل جميع العمليات والأحداث
- **حماية SMS:** منع التكرار، Rate Limiting، كشف الرسائل المشبوهة

### 💾 النسخ الاحتياطي

- **تلقائي:** نسخة احتياطية يومية (تخزن في `filesDir/backups/`)
- **يدوي:** تصدير كامل للبيانات بصيغة JSON عبر زر "تصدير"
- **الاستعادة:** استيراد ملف JSON لاستعادة البيانات
